# DSA Visualizer

An interactive Data Structures and Algorithms visualizer built with C++, HTML, CSS, and JavaScript.

## 🌐 Live Demo

Visit the live website: [-https://sanskarjoshiii.github.io/Data-structure-visualizer/ ](-https://sanskarjoshiii.github.io/Data-structure-visualizer/ )

## 📥 Download

Download the latest version as a ZIP file:
- Click the green **Code** button above
- Select **Download ZIP**

## 🚀 Quick Start

1. Extract the ZIP file
2. Navigate to the `public` folder
3. Open `index.html` in your browser

## 🛠️ For Development

### Prerequisites
- C++ compiler
- Web browser
- Visual Studio Code (recommended)

### Setup
1. Clone the repository:
```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   cd YOUR_REPO_NAME
```

2. Open in VS Code:
```bash
   code .
```

3. Run the build script:
```bash
   ./run.bat
```
